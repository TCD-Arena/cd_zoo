# cd_zoo sample datasets

Small self-contained test sets for quickly exercising the causal-discovery zoo
without downloading external data.

## Time-series sets (linear VAR)

The linear samples are generated via "SYNTH_data_gen" and represent a randomly
sampled linear VAR process in all format cases.

| Folder | Format | Loader | X shape | Notes |
|--------|--------|--------|---------|-------|
| `split_format/` | 10× CSV pairs (`_data.csv` + `_label.csv`) | `load_single_samples` (`example_run.py`) | (5000, 5) per file | rows=timesteps, cols=vars; label is (5,5) `[Effect, Cause]` |
| `joint_format/` | `data.csv` + `labels.p` | `load_joint_samples` (`example_run.py`) | (5000, 50) | same data, concatenated |
| `no_violation_small/` | 10 regime subdirs (`0/`..`9/`) of `.npy` | `load_numpy_ds` (`benchmark.py`) | (100, 5, 250) | CausalRivers generator; stationary (no change points) |

Run e.g.:
```bash
python example_run.py method=var                              # split_format (default)
python benchmark.py ds_name=no_violation_small method=pcmciplus  # numpy format
```

## i.i.d. sets (linear SCM)

Two i.i.d. (non-time-series) test sets — linear structural causal models
`x = (I − B)⁻¹ e` with a random DAG `B` (acyclic by topological ordering).
Each dataset is a single batch of `n_obs` i.i.d. draws (NO temporal order).
Generated by **`generate_iid_samples.py`** (reproducible, configurable).

| Folder | Noise | X shape | Y shape | When methods succeed |
|--------|-------|---------|---------|----------------------|
| `iid_gaussian/` | `e ~ N(0,1)` | (50, 5, 1000) | (50, 5, 5) | PC, GES, DAGMA recover the skeleton; LiNGAM methods cannot orient Gaussian noise (expected) |
| `iid_nongaussian/` | `e ~ Uniform(−√3, √3)` | (50, 5, 1000) | (50, 5, 5) | DirectLiNGAM / ICALiNGAM orient the full DAG; all methods do well |

- **Orientation**: `Y[e, c]` = weight of edge `c → e` (`[effect, cause]`), matching
  cd_zoo's i.i.d. method wrappers — no transpose needed.
- **Structure**: `data_path/<noise>/0/{X.npy, Y.npy, config.yaml}` (the `0/`
  regime subfolder is required by `benchmark.py`'s `load_numpy_ds`).
- **Defaults**: 50 datasets (different random DAGs), 5 variables, 1000
  observations, edge probability 0.3 (≈3 edges/DAG), seed 0.

Regenerate or customise:
```bash
python sample_datasets/generate_iid_samples.py --n-vars 8 --n-samples 100 --n-obs 2000
```

Run i.i.d. methods:
```bash
python benchmark.py ds_name=iid_nongaussian method=lingam restrict_to_n_samples=10
python benchmark.py ds_name=iid_gaussian     method=dagma  restrict_to_n_samples=10
```

### Verified results (first 5–10 datasets)

| Method | Dataset | AUROC (SG_max) |
|--------|---------|-----------------|
| DirectLiNGAM | iid_nongaussian | 1.000 |
| ICALiNGAM | iid_nongaussian | 1.000 |
| DAGMA | iid_gaussian | 1.000 |
| Arrow | iid_nongaussian | 1.000 |
| TabCausal | iid_nongaussian | 1.000 |
| PC | iid_gaussian | 0.931 |
| GES | iid_gaussian | 0.907 |
| AVICI | iid_nongaussian | 0.931 |
| CDFM | iid_nongaussian | 0.944 |

**Identifiability contrast** (the test sets' design goal): on Gaussian noise, LiNGAM methods drop to 0.67–0.84 (edges cannot be oriented from Gaussianity alone — the expected theoretical failure); on non-Gaussian noise they jump to 1.000. PC/GES use Gaussian CI/score tests and dip slightly on non-Gaussian (Uniform) noise.
